# КОЗЛОГОН

Трёхмерный спуск с горы: 20 разных персонажей катятся клубком по неровному склону. Обгоняй соперников, прыгай с трамплинов, подбирай транспорт и доберись до финиша.

В меню можно выбрать гору:

- **Дикие Альпы** — козлы, коровы, олени и лоси; леса и деревни.
- **Кальдера Ада** — демоны, вулканы, крепости и текучая лава вместо ям с пиками.
- **Лунный Хребет** — пришельцы, кристаллы и космические базы; гравитация ещё слабее, чем в Альпах и аду.

Альпы и ад получили прежнюю лунную гравитацию для более мягкого и отзывчивого спуска. Луна стала ещё легче: прыжки и полёт длятся дольше.

На каждой горе 18 снегоходов или скутеров. У каждого из 20 персонажей есть свой голос; в новых мирах меняются голоса и все обитатели, включая публику.

[Играть в браузере](https://blumbutta.github.io/kozlogon/) · [Скачать HTML](https://blumbutta.github.io/kozlogon/downloads/kozlogon.html) · [Скачать ZIP](https://blumbutta.github.io/kozlogon/downloads/kozlogon.zip)

Игра работает в браузере с WebGL. Музыка и звуки включены по умолчанию и начинают играть при первом клике или нажатии клавиши. Кнопка ♫ отключает звук.

## Управление

| Клавиша | Действие |
| --- | --- |
| ← / → или A / D | Плавно поворачивать |
| W / ↑ | Толкаться вперёд |
| Пробел | Прыгнуть |
| E | Бросить бомбу |
| Q | Сбросить капкан |
| R | Погибнуть и возродиться |
| Esc | Пауза |

Бомбы и капканы открываются через 10 секунд после старта. После возрождения действует щит от любых опасностей на 3 секунды. Снегоход или скутер даёт скорость ×3 на 7 секунд и давит существ, а соперников — при ударе спереди. На сенсорном экране есть кнопки управления.

## Локальный запуск

Готовая игра находится в `dist/`. Самостоятельный HTML и ZIP для скачивания — в `dist/downloads/`.

Для запуска готовой сборки:

```sh
python3 -m http.server 4173 --directory dist
```

Открой `http://localhost:4173`.

Для изменения игры нужны Node.js 18+ и pnpm 10:

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm start
```

## Публикация

GitHub Actions публикует содержимое `dist/` на GitHub Pages после обновления ветки `main`. После изменения исходников собери игру и добавь обновлённый `dist/game.js` в коммит. Страница использует относительные пути и работает в адресе репозитория.

## Внутри

Three.js рисует мир, Cannon ES рассчитывает физику. Модели, эффекты, музыка и голоса создаются программно; игре не нужны внешние серверы и CDN.

На телефоне газ и поворот можно удерживать отдельными пальцами, одновременно нажимая прыжок, бомбу или капкан. Способности срабатывают сразу при касании. Двойное нажатие на игровом экране не увеличивает страницу.
