# КОЗЛОГОН

Трёхмерный спуск с горы: 20 разных персонажей катятся клубком по неровному склону. Обгоняй соперников, прыгай с трамплинов, подбирай транспорт и доберись до финиша. Можно играть одному с ботами или вместе с друзьями в приватной комнате.

[Играть в браузере](https://blumbutta.github.io/kozlogon/) · [Скачать HTML](https://blumbutta.github.io/kozlogon/downloads/kozlogon.html) · [Скачать ZIP](https://blumbutta.github.io/kozlogon/downloads/kozlogon.zip)

## Горы и персонажи

- **Дикие Альпы** — козлы, коровы, олени и лоси; леса и деревни.
- **Кальдера Ада** — демоны, вулканы, крепости и текучая лава вместо ям с пиками.
- **Лунный Хребет** — пришельцы, кристаллы и космические базы; гравитация слабее, прыжки и полёт длятся дольше.

На каждой горе 18 снегоходов или скутеров. У каждого персонажа свой голос; в новых мирах меняются голоса и все обитатели, включая публику. После прыжка с трамплина персонаж выпускает вперёд пять ракет с небольшими перерывами и случайным разбросом направления.

Игра работает в браузере с WebGL. Музыка и звуки включены по умолчанию и начинают играть при первом клике или нажатии клавиши. Кнопка ♫ отключает звук.

## Играть с друзьями

1. Выбери гору и персонажа, нажми **«Играть с друзьями»**, введи имя и создай комнату.
2. Нажми **«Пригласить друзей · скопировать ссылку»** и отправь ссылку друзьям. Комнаты доступны только по приглашению; общего списка комнат нет.
3. При входе друг задаёт имя. Предложенное случайное имя можно изменить. Сервер выдаёт свободного персонажа; в лобби можно выбрать другого. Все 20 персонажей в заезде разные, а свободные места занимают боты со значком **🤖**.
4. Создатель может начать заезд сразу, даже один. Когда соберутся хотя бы 4 подключённых игрока, начнётся отсчёт на 1 минуту. Выход любого игрока сбрасывает отсчёт; при наличии 4 игроков начинается новая минута.

В заезде до **20 живых игроков**. После старта или при занятых местах новые участники становятся наблюдателями: можно выбрать, за кем смотреть, и переключаться стрелками. После своего финиша игрок также может наблюдать за оставшимися участниками.

Первый финиш запускает минуту до конца общего заезда. Если за эту минуту финишируют все 20 участников, результаты открываются раньше. После результатов создатель нажимает **«Вернуться в лобби»**: ссылка и имена сохраняются, трасса и боты сбрасываются, персонажей можно поменять. Наблюдатели получают освободившиеся места в следующем заезде. Создатель снова запускает гонку или ждёт автоматического старта.

Пауза в сетевой игре открывает меню, пока остальные продолжают спуск. При коротком обрыве связи клиент переподключается; место сохраняется до 20 секунд. Если создатель выходит, управление комнатой передаётся другому подключённому участнику.

Сервер рассчитывает общую физику, опасности, попадания и результаты. Браузеры рисуют мир, сглаживают движение соперников и предварительно рассчитывают движение своего персонажа. При перезапуске серверного процесса комнаты теряются: после переподключения потребуется создать новый заезд.

## Управление

| Клавиша | Действие |
| --- | --- |
| ← / → или A / D | Плавно поворачивать |
| W / ↑ | Толкаться вперёд |
| Пробел | Прыгнуть |
| E | Бросить бомбу |
| Q | Сбросить капкан |
| R | Погибнуть и возродиться |
| Esc | Пауза / меню |

Бомбы и капканы открываются через 10 секунд после старта. После возрождения действует щит от любых опасностей на 3 секунды. Снегоход или скутер даёт скорость ×3 на 7 секунд и давит существ, а соперников — при ударе спереди. Лёд сильно ускоряет спуск; убийства дают ярость и дополнительную скорость.

На телефоне газ и поворот можно удерживать отдельными пальцами, одновременно нажимая прыжок, бомбу или капкан. Способности срабатывают при касании. Двойное нажатие на игровом экране не увеличивает страницу. У наблюдателей кнопки управления скрыты.

## Локальный запуск

Готовая игра находится в `dist/`. Самостоятельный HTML и ZIP для скачивания — в `dist/downloads/`. Скачанный HTML работает без установки для одиночной игры; для мультиплеера открывай игру на GitHub Pages или через локальный HTTP-сервер.

Для просмотра готовой сборки:

```sh
python3 -m http.server 4173 --directory dist
```

Открой `http://localhost:4173/`. По умолчанию клиент подключает сетевые комнаты к `https://kozlogon-server.onrender.com`.

Для разработки нужны Node.js 24 и pnpm 10:

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run build:server
pnpm test
```

Запусти сервер и просмотр игры в отдельных терминалах:

```sh
npm run start:server
```

```sh
pnpm start
```

Для локального мультиплеера открой `http://localhost:4173/?server=http://localhost:10000`. Ссылка-приглашение сохраняет выбранный адрес сервера. Для проверки с других устройств используй доступный им адрес сервера и разреши origin страницы в `ALLOWED_ORIGINS`; страница HTTPS должна подключаться к серверу HTTPS/WSS.

## Сервер на Render

`server/main.mjs` и `server/rooms.mjs` — исходники сетевого сервера. Команда `pnpm run build:server` собирает их вместе с физикой и зависимостями в **`server/index.mjs`**. Этот готовый файл хранится в репозитории, поэтому существующие настройки Render продолжают работать без установки пакетов при развёртывании:

| Поле | Значение |
| --- | --- |
| Тип сервиса | Web Service |
| Repository | `blumbutta/kozlogon` |
| Name | `kozlogon-server` |
| Language | Node |
| Branch | `main` |
| Region | Frankfurt |
| Root Directory | Оставить пустым |
| Build Command | `node --check server/index.mjs` |
| Start Command | `npm run start:server` |
| Compute | `0.5c-512mb` — выбранный небольшой сервер |
| Health Check Path | `/health` |
| Environment Variables | `NODE_ENV=production` |
| Auto-Deploy | On Commit |

Параметры также записаны в `render.yaml`. Сервер слушает `0.0.0.0:10000`, а на Render использует предоставленную переменную `PORT`. `/health` отвечает `200` и `{"ok":true}`. `/` показывает статус сервера; WebSocket работает по `/ws`.

По умолчанию действуют ограничения **`MAX_ROOMS=4`** и **`MAX_ACTIVE_RACES=2`**: четыре комнаты могут существовать одновременно, но физика рассчитывает до двух активных заездов. Это стартовые ограничения для сервера с 0,5 CPU, а не гарантия его производительности при 20 игроках и большом числе наблюдателей. Перед увеличением лимитов нужны проверка нагрузки, памяти, задержек и исходящего трафика. Если оба заезда уже идут, следующая комната должна подождать.

Переменная `ALLOWED_ORIGINS` принимает разрешённые origin через запятую. По умолчанию разрешён `https://blumbutta.github.io`, а также локальный просмотр через `http://localhost` и `http://127.0.0.1`. При публикации фронтенда на другом домене добавь его origin. База данных и постоянный диск для этой версии не нужны.

## Публикация и устройство проекта

GitHub Actions публикует содержимое `dist/` на GitHub Pages после обновления ветки `main`. Render отдельно запускает сервер из той же ветки. После изменения исходников собери клиент и сервер и добавь обновлённые `dist/game.js` и `server/index.mjs` в коммит; скачиваемые HTML/ZIP также должны соответствовать клиентской сборке.

Three.js рисует мир, Cannon ES рассчитывает физику, WebSocket передаёт команды и состояния. Модели, эффекты, музыка и голоса создаются программно. Одиночная игра работает без внешнего сервера и CDN. Сервер хранит комнаты в памяти и проверяет управление, способности, смерти и результаты; частные приглашения используют случайный идентификатор комнаты.
